# Coordinator, Diagnostics & Inspector data

TF-B29–31. Zustände: initialized -> evaluating -> evaluated/staged -> committed (optional nächste Population) oder blocked/cancelled. Ein immutable committed Snapshot enthält Generationsergebnis, Champion, History-Index, adaptive State, Folgepopulation nur wenn Budget erlaubt. Stage sämtliche erwarteten Resultate nach kanonischen Keys, reject duplicates/missing/unknown, falsche IDs/Verträge/Generation/Genominhalt. Unabhängige gültige Auswertungen dürfen fertig werden, ungelöste Fehler blockieren Commit. Keine Selektion über Teilpopulation, keine Fake-Score, kein Löschen gültiger Eliten. Wenn Generationserzeugung an Slot127 scheitert, bleiben letzter committed Snapshot, RNG, Champion und History exakt unverändert; Fehler in separatem Status/Log. Atomar auch am letzten Budgetende ohne Folgepopulation. Eine temporäre Infrastrukturwiederholung nur einmal unter exakt gleicher Konfiguration; bei deterministischem Modell-/Simulationsfehler keine Wiederholung als Chance. Keine automatische Retry von Programmfehlern. Externes Stoppen nur nicht-selektionsfähiger Abbruch; persistente Wiederaufnahme D13.

GenResult: IDs, Vertrag, best/worst/mean/median/Q1/Q3 Fitness (sortierte Werte, lineare Quantile Index (n-1)*q), successCount/rate, gültige Runden und Zeiten (fehlend=null, nicht 0), Fortschritt, Roh-/Strafkomponenten, Abschlussgründe, versuchte/erfolgreiche Auswertungen, simulierte Zeit, Diversity, Mutations-/Crossover-/Elite-/Immigrantstatistik, Stagnationszähler, p/alpha vor/nach, Champion-ID. Kompakte records pro Kandidat. Walltime, RAM, Renderer/FPS, Diagnose separat, nie Ranking. Snapshots defensive Kopien/immutable plain data; typed arrays privat. Optional Trace selektiver Kandidaten: Parameterindex/alt/neu, Elternherkunft, Sensoren/Fahrverlauf/Neurontrace aus echter Ausführung, begrenzt durch explizites Sample-/Speicherbudget; default kompakt. Keine synthetischen Inspector-Daten als echt ausgeben. Optional Trace darf keine Physik, Fitness, Auswahl oder RNG verändern. Daten/abfragbare Historie jetzt; visuelle Population-/Evolution-Übersicht D12, Genomstammbaum, Heatmaps, Diversity-Projektionen, Brain Surgery, Replay/Time Machine nach Launch. Detaillierte historische Rekonstruktion nur wenn relevante Genome/Trace tatsächlich gespeichert wurden.
