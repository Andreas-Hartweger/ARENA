# Mutation Engine v1

TF-B19–21. Pro regulärem Nachkommen unabhängige Kopie (nach evtl. Crossover), additive normalverteilte Mutation. Global p∈[0,1] Default .05, alpha∈[.01,2] Default .20. Absoluter Vergleichsmodus sigma∈[.001,1]; adaptives alpha nur relativ. Pro Layer s=sqrt(2/denom), denom = fanIn+fanOut bei tanh/linear-output, fanIn bei ReLU, fanIn*1.0001 bei Leaky. Null-Bias nutzt Gewichtsskala derselben Schicht. Normale sigma = alpha*s bzw. absolute sigma; multipliziere Schicht- und ggf. Bias-Stärkefaktoren. Effektives p=min(1,p*Schicht-p-Faktor*Bias-p-Faktor). Alle Faktoren 0..2, Default1. Bei p_eff=0 ODER sigma_eff=0 Parameter nicht mutierbar (auch keine erzwungene Auswahl). Freigegebene Parameter in bestehender Indexreihenfolge unabhängig Bernoulli wählen. Wenn kein Treffer und mindestens ein mutierbarer Parameter vorhanden: genau eine uniforme Auswahl unter mutierbaren Indizes; wenn keine: unverändert. Keine Retry-Schleife für tatsächlich geänderte Bytes. p=0 deaktiviert. Pro ausgewähltem Parameter Bernoulli largeProbability 0.. .30 Default .05; largeMultiplier 1..10 Default5. Delta=sigma_eff*(large?mult:1)*Z. Z via Seed-Vertrag. Neue Werte clamp auf symmetrische konfigurierte Grenzen ±8 Gewichte, ±4 Bias. Grenzen endlich positiv; vorgeschlagener numerischer Sicherheitsbereich max 1e6 (technische Sicherheitsgrenze, nicht Produkt-Tuning). Bei Import außerhalb ablehnen oder ausdrücklich neue Konfiguration; nicht stillschweigend ändern. Nichtendliche Zwischenwerte Fehler, kein clip von NaN/Inf. Init-Grenzen müssen mögliche D09-Werte zulassen. Diagnostik: pro Layer und Typ eligible/selected/changed/normal/large/clipped, Delta mean abs, RMS, max abs, optionale index/old/new/type. Unveränderte Parameter nicht versehentlich überschreiben. Keine Änderungen an Eltern oder Elite.

Standard: erwartete 427.35 Selektionen vor Mindestauswahl, 21.3675 große, 405.9825 normale. σ je Schicht .016903..., .0408248..., .0648886...; Verteilung vor Clipping; statistisch nicht mit tatsächlicher Fahrintelligenz verwechseln. Relative RMS vor Clipping = alpha*sqrt(p*(1-q+q*m^2)). Mutation und Kreuzung können schlechtere Modelle erzeugen.
