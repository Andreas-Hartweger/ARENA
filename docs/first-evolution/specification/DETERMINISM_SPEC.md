Draws: `U=next()` [0,1), Bernoulli U<p auch bei 0/1 (außer deaktivierte Operatoren/Parameter, dann keine Draws); ganzzahlige gleichmäßige Wahl: rejection sampling uint32 = floor(U*2^32), verwerfe x>=floor(2^32/k)*k; return x%k. k=1 direkt 0 ohne Draw. Fisher-Yates von n-1 bis 1; Tournament partielle Ziehung i=0..k-1, swap i mit i+uniform(n-i). Crossover: eigener choice Stream, bei aktiviertem p ein Draw je regulärem Kind; separater cross Stream für Genomindizes/Neuronen in Layoutrichtung. Mutation: erst alle Bernoulli-Draws in kanonischer Parameterreihenfolge, dann evtl. Mindestauswahl, danach für jeden ausgewählten aufsteigenden Index ein Large-Draw und Box-Muller 2 Draws (kein Cache); u1=1-U1 in (0,1], u2=U2; Z=sqrt(-2*ln(u1))*cos(2*pi*u2). Auch q=0/1 definierter Draw. Deaktivierte Mutation liefert ohne Draw. Feste Domains isolieren Diagnose/Initialisierung von Operatoren.
