## Role gate (both official roles)
Same frozen exact genome/version and matching contracts for every required test. Standard valid round; 54/60 total and >=16/20 per group. Standard lap <=75s Starter, <=50s Performance; median of successful holdout lap times <=75s Starter, <=60s Performance (exclude start approach, report task duration separately). No severe contact (normal approach speed >=10m/s) on any final 60 test, including failed episodes. >=ceil(.9*successful) successful episodes have zero collision clusters. Median axle-weighted grass exposure on successful tests <=2s, max <=10s. Require true unsaturated raw contact/grass metrics, not infer from normalized penalty; instrument accepted events if absent. Three-lap 10/12 complete, standard 3 laps complete, 360s, no resets and no severe contacts in any mandatory multi-lap run; D10 valid gates and existing no-progress. Technical clarification: also require no severe contacts on mandatory standard single-lap (quality protection, stricter explicit proposal); all other thresholds on defined test set only. No missing metrics or failed infra counted as successful. A reproducible transient infra failure may retry identical assignment once under budget; preserve both attempts, never replace case. If unfinished/inconclusive, gate pending not pass. Optional Recovery certificate >=12/18, each >=3/6, return <=20s and 20m within next 5s; no resets. Specialist must satisfy Starter base gates plus its declared specialty measured with pre-frozen extra criterion (e.g. recovery cert or comparable measured compute efficiency vs Starter); no unsupported official role. Max 3 distinct candidate fingerprints across roles preselected, roles and all criteria before holdout. No requirement to publish all three. No automatic relaxation.

## Statistics and audit
Valid lap times null if no success; median/quantiles linear (n-1)q, success denominators explicit. Report raw events, total errors, per group; same exact scenario comparison, paired differences and common successful subset time comparison also report coverage, avoid survivorship bias. Seed-level distributions; time to first success right-censored at budget. 3 seeds not strong general inference; fixed 60 panel not random population CI unless sampling assumptions specified. Deterministic repeats not independent. Compare prior models where compatible, >5pp success drop or >5% median time increase investigated, not silently waived; >15% throughput regression investigated same-work >=3 replicates. No generalized road/weather/opponent claim. Audit independent arithmetic, valid progress, time, corrections, repeated gate, wall exploiting, sensor leakage; select fastest, unusual, failed traces before reviewing, retain exact replay instructions. Technical bug invalidates affected results; after correction new contract/evidence. Holdout failure: do not pick new candidate based on it; keep research record, new independently frozen panel if further authorized.
