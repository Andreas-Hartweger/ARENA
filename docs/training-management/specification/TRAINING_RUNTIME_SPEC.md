## Worker und Resource Management
Coordinator ist einziger Scheduler/Committer. Simworker ein aktiver Job. h = navigator.hardwareConcurrency valid positive int, fallback 1; cap=min(16,max(1,h-2)); Eco floor(h*.25), Balanced floor(h*.5), Performance floor(h*.75) jeweils clamp1..cap; Custom 1..cap. h12=3/6/9 cap10; h16=4/8/12 cap14. Profile verwaltete RAM-Budgets 256/512/1024 MiB; Custom bounded nach konservativer Preflight, v1 Startwert max 4096 MiB und Browserfähigkeit (TF-C, nicht OS-Garantie). Reserve für 2 Populationen, stage results, active worlds, worker genome copies, diagnostics, packet/import/export, storage writes; actual tracked bytes + estimate für Overhead, nicht als Browser-RSS ausgeben. Keine unbounded tasks/messages, Workerwechsel nach Abschluss aktiver Episode (drain), nicht kill zur Geschwindigkeitsoptimierung. UI optional throttle, Background Browser limits transparent.
## Protokoll v1
Envelope {protocolVersion,runId,sessionId,segmentId,generation,slot,scenarioIndex,jobId,attempt,workerLease,contractId,modelKey,genomeHash,scenarioSeed,type,payload}. Lifecycle handshake Ready -> Assign -> Running -> PauseAck/Result/Fault -> Idle; CancelAck; Shutdown. Command seq monotonic je session, ACK commandId and observed state. Validieren Typ, Länge, Finite, IDs, Assignment, Version, payload shape, allowed state; result maps to coordinator-owned Genome, never trust worker copy as parent. Assigned job key includes immutable config/evaluation contract, seed; retry same key attempt 1 only transient infra, new lease; lost/expired lease stale. Identical duplicate ignored, conflicting duplicate fault; old completed/invalid session ignored/logged bounded; unassigned/malformed current messages fault. No race between cancel and late commit: coordinator serialized event stream, fencing. One critical result per job retained until ACK; bounded credit/backpressure; only UI snapshot coalescing allowed. Stalled vs dead worker: heartbeat/liveness and browser suspend distinguish, no fitness penalty for real time. Timeout never pretends pause.
## Scheduling and deterministic commit
Precompute canonical slot/scenario jobs; assign next available worker; no arrival-order selection or RNG. Stage all results, validate complete expected rows, aggregate canonical slot/scenario order using existing D11 weighted mean (not strict cross-scenario success lexicographic; unchanged). Use same Genome and ranking/fitness code. Separate prepare summary/goal evaluation/reproduce/publish; preserve old commit semantics on fixed reference budget. Stage next population only if another generation authorized. Commit atomically history/champion/adaptation/next population (or final no next). Stage fail retains last complete state. Progress/trace may be preview only. Job retry not extra logical evaluation but measured attempt cost. No cache substitution for elite reevaluation. Session/time/diagnostic fields excluded from deterministic equality; canonical genome bytes, raw fitness, rank, lineage, adaptive states exact on same runtime. Across runtime compare independently; tolerance <=1e-9 for fixtures, no promise full run same.
