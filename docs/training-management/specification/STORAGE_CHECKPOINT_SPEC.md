IndexedDB v1 for app-origin. Separate stores (logical names adjustable): schema/settings, profiles/models/versions/manifests, content blobs, performance/lineage, run/revision/segment, generation summaries, checkpoint manifests, queue/templates/series, refs/protection/trash, staging/import/export, lease. Typed API transactions; in-memory adapter for unit tests, real IDB integration mandatory. Single app training lease across same origin/browser profile; prefer Web Locks when supported + DB fencing token (monotonically increasing epoch/session) checked in same readwrite transaction for every mutation. No unsafe TTL-only takeover on suspended tab; fallback fail closed/single writer explicit coordinated release. Other tabs read-only for owned run. DB versionchange closes/blocks appropriately; no destructive auto reset. Browser profiles/computers cannot share lease, transfer handled as provenance branch. No guarantee storage outside origin. Request persistent storage if supported, display estimate and granted status, catch quota failures. Origin fixed in future launcher.
## Canonical boundary checkpoint
Initial before G0, after each full evaluated generation by default, and at final completion. `checkpointPhase` = readyToEvaluate (population contains exact next jobs, no pre-eval results) or terminal (no next generation; status/reason). Include format/runtime/physics/sensor/evolution/digest versions, full evaluation contracts/scenarios/weights, original/revision config+pending edits, run/segment IDs and global/segment next generation, ordered members/genomes/IDs/origin/parents, adaptive state, champion + genbest references, immutable history index/summaries/necessary lineage/metrics, masterSeed/domain contract and RNG states if stateful, budgets consumed/logical counters/goal streaks, active elapsed/uncertain time, series/queue refs as appropriate, protection/ref closure and byte digests. Initial checkpoint has Gcount0 and next G0; after completed Gk, Gcount=k+1 (global cumulative), next generation exactly k+1 unless terminal; local segment index separate. Never serialize private JS instances directly: explicit DTO export/import/validation/hydrate, reconstruct prototypes from approved data. Recompute digests, verify graph/reference invariants and required counters. Source segment evaluation results remain distinct. No mid-episode durable resume v1; exact pause RAM retains full state. Restored active state new SessionID, no automatic dispatch until user explicitly resumes. Terminal CP view/export only, new Run for more learning. Older CP with newer history -> fork new Run with parent checkpoint, map IDs consistently, no overwrite or falsely exact original continuation. Cross-runtime exact only if supported/proven; otherwise new compatible run with explicit warning.
## Commit and durability
At boundary build immutable next-state DTO and necessary blobs; validate and hash outside IDB transaction; bounded staging with own ownership and cleanup; publish all pointers + metadata + checkpoint + reference deltas atomically in one transaction checking lease. No await unrelated async inside open IDB transaction that can auto-close. Use strict durability when supported; transaction completion is required, not request success. Keep old checkpoint and necessary refs until new commit confirmed. If stage or commit aborts, no visible partial dataset, remove only unreferenced staging after owner check. Durable status separate from RAM-confirmed generation; on mandatory save failure hold scheduler before next job, preserve last committed CP, show unsaved boundary; retry same stage, no duplicate reproduce. Initial mandatory failure no dispatch. Explicit volatile mode opt-in (warning, no claim durability) and no automatic queue continuation on unresolved failure. User can export safe data. Recovery finds latest complete validated CP, falls back older on corruption, preserves invalid evidence metadata if safe, no auto delete. Never guarantee against hardware failure, site-data deletion or eviction. External backups necessary.
## Autosave/retention
Default every generation + initial/final; intervals 1/5/10/25, optional real time request coalesced at next boundary. One write operation; required saves barrier before next generation. Manual save model/Champion (actual evaluated status), last durable or staged full boundary CP, mark next boundary pending, no auto-resume from paused. Protected manual saves and milestone, official models, active/queued refs, last 3 autoCP per relevant run; keep at least prior valid point when available. Delete old unprotected after confirmed new commit; retain 3 plus write reserve, if cannot fit block not delete protected. Compact history and selected traces, no unbounded all-genome history. Reference graph strong roots (model versions, checkpoints, active jobs/queue, export/import pins, protected champions, trash until purge); lineage refs may be weak tombstone when source removed. Compute GC by reachable graph + transaction, shared blobs counted once; protect on race. Preview list exact affected IDs/managed bytes, revalidate on commit; archive hides, trash reversible default30d, purge expired only unprotected; manual delete confirmation and impact. No purge of active, queued, official/milestone, recoverable CP dependencies; explicit unprotect only where policy permits. Keep metadata tombstone for historical lineage.

Default durable app budget 1GiB (1073741824 bytes) configurable by actual quota; reserve stage+new CP+old CPs+overhead; transaction failures handled even estimate passes.
